# Güvenli Yaşam — Konut Altı Sığınak Rehberi

Bu klasör, mevcut web sitesinin yerine geçirilebilecek statik bir Türkçe bilgilendirme sitesi taslağıdır.

## Dosyalar
- `index.html`: tüm sayfa içeriği
- `style.css`: tasarım ve mobil uyumluluk
- `script.js`: mobil menü ve yıl bilgisi

## Yayına almadan önce
1. `index.html` içindeki “GÜVENLİ YAŞAM” marka adını tercih ettiğiniz marka adıyla değiştirin.
2. `info@example.com` adresini gerçek iletişim adresinizle değiştirin.
3. Sitenin sahibi/işletmesi, adres, telefon, gizlilik ve iletişim bilgilerini ekleyin.
4. Mevzuat bilgilerini yayına almadan önce belediye ve ilgili resmî kurumlarla doğrulayın.
5. Bu içerik bilgilendirme amaçlıdır. Yapısal ölçüler, donatı detayları, patlama yükleri veya uygulama talimatları vermez. Her gerçek proje yetkin mühendislerce tasarlanmalı, gerekli izinler alınmalı ve denetlenmelidir.

## GitHub Pages'e yükleme
GitHub deposunda mevcut dosyaları yedekleyin. Ardından bu klasördeki `index.html`, `style.css`, `script.js` ve `README.md` dosyalarını deponun yayınlanan kök dizinine yükleyin. GitHub Pages ayarlarında doğru branch ve klasörün seçili olduğunu doğrulayın. Değişikliklerin yayına yansıması birkaç dakika sürebilir.

Dış yazı tipi Google Fonts üzerinden yüklenir; bağlantı yoksa sistem yazı tipleriyle devam eder.
