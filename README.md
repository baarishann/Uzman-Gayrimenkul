# Uzman Gayrimenkul PWA

Bu proje, telefona uygulama gibi kurulabilen ücretsiz başlangıç sürümüdür.

## İçerik
- Ana sayfa
- İlan listesi
- Arama ve kategori filtresi
- İlan detay penceresi
- WhatsApp ve telefonla iletişim
- Gayrimenkul gönderme formu
- Basit ilan yönetim paneli
- PWA / Ana ekrana yükleme desteği
- Çevrimdışı temel önbellek

## Çalıştırma
Dosyaları bir web sunucusunda yayınlayın. PWA özellikleri için HTTPS gerekir.
Ücretsiz yayınlama seçenekleri: GitHub Pages, Cloudflare Pages veya Firebase Hosting.

## Önemli
İlk sürümde yönetim panelinden eklenen ilanlar tarayıcının localStorage alanında tutulur.
Yani başka telefonda otomatik görünmez. Sonraki aşamada Supabase/Firebase ile ortak veritabanına bağlanabilir.
